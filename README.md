# Fun_with_up

Top-down 2D game: Fun with UP.

Trash piles collecting. Ark park system. Beams into the house. Soul workshop. Quarks and nanos. Control boards. Clean vs dirty. Soul chair. Levels 0-9.

Concept art is the freeze frame of the board in play. This is the start.

Built from the map: Exeter to clear, ark only up, never with trash. Stacks. Sats. Heart as failsafe. Ohm. Mirror nexus. TURRET VIEW. Game of love.

## Play the first slice

Open [index.html](https://pptensentities-ai.github.io/Fun_with_up/) or clone and open `index.html` in any mobile browser.

- Touch or drag to move.
- Walk over trash piles to clean them.
- Ark core in the center.
- Beams on the walls.
- Soul chair in the corner.

Mobile-first. Works on phone right now.

## Core

- Walk the house / city / coast to coast.
- Clean dirty spots the blind leave.
- Command Exeter. Take out trash. Ark up.
- Beams red and blue.
- Proper stack or jester.
- Protection, higher power, loving embrace, clean flow.
