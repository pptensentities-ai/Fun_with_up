# Fun_with_up

Top-down 2D game: Fun with UP.

Trash piles collecting. Ark park system. Beams into the house. Soul workshop. Quarks and nanos. Control boards. Clean vs dirty. Soul chair. Levels 0-9.

Concept art is the freeze frame of the board in play. This is the start.

Built from the map: Exeter to clear, ark only up, never with trash. Stacks. Sats. Heart as failsafe. Ohm. Mirror nexus. TURRET VIEW. Game of love.
